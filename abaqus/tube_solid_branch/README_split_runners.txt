Tube-solid branch runner scripts
================================

Use the size-specific runners. The generic runner is deprecated.

2x2x2:
    abaqus cae noGUI=abaqus/tube_solid_branch/abaqus_batch_run_tube_solid_222.py

4x4x4:
    abaqus cae noGUI=abaqus/tube_solid_branch/abaqus_batch_run_tube_solid_444.py

Input JSON folders:
    data/rep222/json/
    data/rep444/json/

Output folders:
    runs/tube_solid_222/
    runs/tube_solid_444/
